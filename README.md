# Chalkman Business for Android: downloads

Official download page and signed APK releases for **Chalkman Business**, by RG DEVs.

**Download:** https://kenrodgersutugi-tech.github.io/chalkman-business-releases/

This repository holds only the download page (`docs/`) and the signed release files.
The source code is private. Releases are published by `scripts/release.mjs` in the private
repository; the app checks `releases/latest/download/latest.json` for updates and verifies each
APK's SHA-256 before Android installs it.
